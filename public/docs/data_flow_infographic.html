Playence — Flusso dati wearable & n8n
Infografica interattiva del percorso dei dati dai dispositivi indossabili all'analisi AI
Passo 1
FE attiva il polling
L'utente preme "Avvia analisi performance". Il FE chiama il BE con l'id dell'evento.
POST /api/wearable/sessions { eventId }
Passo 2
BE recupera l'evento
Il BE usa l'eventId per trovare l'evento nel DB e leggere la lista dei partecipanti e i loro device.
SELECT * FROM events WHERE id = ?
Passo 3
Google Fitness API
Il BE chiama la Google Fitness API per ciascun partecipante raccogliendo FC, calorie, distanza e O₂.
GET fitness.googleapis.com/v1/users/me/...
Passo 4
Salvataggio nel DB
Ogni lettura viene salvata come WearableReading collegata all'evento, partecipante e timestamp.
INSERT INTO wearable_readings (...)
Nodo 1
Partenza
Webhook trigger. Il BE chiama questo endpoint al momento della richiesta dell'utente.
POST webhook/performance-analysis
Nodo 2
Dati
Riceve parametri biometrici wearable (FC, calorie, distanza, durata) e commento tecnico del coach. Solo con consenso utente.
raw · biometrica + coachComment
Nodo 3
Fa la media dei dati
Confronta i dati dell'utente con la media degli altri partecipanti all'evento per costruire il comparison object.
user_data vs avg_group
Nodo 4
AI Agent
Cuore dell'analisi. Riceve biometrica + commento coach. Usa Modello AI + Structured Output Parser per produrre JSON strutturato.
→ { summary, comparison, strengths, improvements, coachMarkedComment }
Nodo 5
Code in JavaScript
Formatta e organizza il JSON prodotto dall'AI per renderlo leggibile e pronto per i nodi successivi.
format(aiOutput) → report
Nodi 6–7
Crea + Inserisci documento
Genera automaticamente un documento su Google Docs con il report completo. Aggiorna il documento con i dati formattati.
Google Docs API · create + update
